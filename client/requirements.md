## Packages
recharts | For visualizing process metrics and averages
framer-motion | For animated Gantt charts and smooth transitions

## Notes
The application relies on a C++ backend exposed via Node.js at /api/simulation/run.
The shared schema defines ALGORITHMS, Process, and SimulationConfig.
Theme is Earth-tone (Beige/Brown) with system-programming aesthetics.
